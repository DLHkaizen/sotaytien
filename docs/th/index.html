Moneybook: บันทึกเงินและหนี้

ให้ยืม-ยืมเงิน ไม่ลืมอีก

ใครติดเงินคุณ? คุณติดเงินใคร? บันทึกรายการละไม่กี่วินาที แยกสกุลเงินตามกระเป๋า ไม่ต้องมีบัญชี ไม่มีโฆษณา ข้อมูลอยู่ใน iPhone ของคุณ

ดาวน์โหลดบน App Store

สี่ปุ่ม ไม่มากกว่านั้น

รายรับ รายจ่าย ให้ยืม ยืมเงิน อยู่บนหน้าแรก กรอกจำนวนเงิน แตะบันทึก เสร็จ

สมุดหนี้ทั้งสองทาง

"คนอื่นติดเรา" และ "เราติดคนอื่น": ใคร เหลือเท่าไร ตั้งแต่เมื่อไร บันทึกการคืนบางส่วน คืนครบ หรือตัดหนี้สูญได้

หกตัวเลข

ตามวัน สัปดาห์ เดือน หรือปี แตะตัวเลขเพื่อดูรายการที่ประกอบเป็นตัวเลขนั้น

ให้ยืมไม่ใช่รายจ่าย

เงินที่ให้ยืมไม่นับเป็นรายจ่าย และเงินที่ยืมมาไม่นับเป็นรายรับ ตัวเลข "เดือนนี้ใช้ไปเท่าไร" จึงเป็นตัวเลขจริง

ลืมบันทึก? ใส่ย้อนในวันนั้นได้

เปิดรายงานรายวัน ย้อนไปวันที่ลืม แตะรายรับหรือรายจ่าย รายการจะอยู่ในวันที่กำลังดูอยู่

ข้อความทวงเงินแบบสุภาพ

แอปเขียนข้อความพร้อมยอดคงเหลือให้ คุณอ่านแล้วเลือกเองว่าจะส่งทางไหน แอปไม่ส่งแทนคุณ

เทียบกับช่วงเดียวกันของรอบก่อน

ใต้ตัวเลขใช้จ่ายในรายงานสัปดาห์ เดือน ปี: ครึ่งแรกของเดือนนี้เทียบกับครึ่งแรกของเดือนก่อน ไม่เอาครึ่งเดือนไปเทียบกับทั้งเดือน

เตือนตอนเย็น

ปิดอยู่จนกว่าคุณจะเปิด เลือกเวลาได้เอง วันไหนบันทึกแล้วจะไม่เตือน

กี่กระเป๋า กี่สกุลเงินก็ได้

เงินสด ธนาคาร อีวอลเล็ต ตัวเลขใหญ่คือยอดรวมกระเป๋า แตะเพื่อดูทีละกระเป๋า กระเป๋าละหนึ่งสกุลเงิน (บาท ดอลลาร์ ด่ง และอื่นๆ) รวมยอดแยกตามสกุลโดยไม่แปลงค่า การโอนระหว่างกระเป๋าไม่ใช่ทั้งรายจ่ายและรายรับ

หมวดหมู่ของคุณเอง

ตั้งชื่อตามชีวิตจริง เช่น อาหาร ค่าน้ำค่าไฟ ค่าเดินทาง รายงานกรองตามกระเป๋า ตามหมวดหมู่ หรือทั้งสองอย่างก็ได้

วิดเจ็ตบนหน้าจอโฮม

ดูยอดที่ให้ยืมและยอดค้างจ่ายโดยไม่ต้องเปิดแอป แตะเพื่อเปิดหน้าหนี้

สำรองและกู้คืน

สำรองอัตโนมัติไปยัง iCloud ของคุณเอง หรือเป็นไฟล์ CSV และ JSON ผู้พัฒนาอ่านข้อมูลของคุณไม่ได้

ข้อมูลของคุณเป็นของคุณ

ไม่มีบัญชี ไม่มีโฆษณา ไม่ติดตาม ปิดการสำรองไปยัง iCloud แล้วแอปทำงานออฟไลน์ทั้งหมด

โหมดสว่าง มืด และวอลเปเปอร์ของคุณเอง

ตามการตั้งค่าของ iPhone หรือเลือกในการตั้งค่า ใส่วอลเปเปอร์ของคุณเองได้ ตัวเลขเงินยังอ่านง่ายเสมอ

แปดภาษา

ไทย อังกฤษ เวียดนาม ญี่ปุ่น เกาหลี อินโดนีเซีย และจีน (ตัวย่อและตัวเต็ม) เปลี่ยนได้ทันทีในการตั้งค่า ไม่ต้องเปิดแอปใหม่ เงินด่งเขียนแบบเวียดนามในทุกภาษา
